# FE6 ADMIN — Universal Admin Script

~200 commands, full admin GUI. Works across all Roblox games.

## How to Use

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fungamer1234/FE6-admin/main/FE6_ADMIN.lua", true))()
```

Press **RightShift** to toggle the GUI.

## Features

- ~200 admin commands
- Full GUI with organized command categories
- Player management (kick, ban, mute, spectate, TP, bring, follow)
- Server management (shutdown, lock, clear)
- Character tools (fly, noclip, speed, jump, gravity, godmode)
- Visual tools (ESP, fullbright, no fog, zoom, third person)
- Chat commands and spam tools
- Fun commands (dance, spin, sit, ragdoll, fire, explode)
- Works universally across all Roblox games
